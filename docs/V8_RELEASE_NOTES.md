# あとすこし v8

`index.html` をブラウザで開いて使います。画像・音声もHTML内に含まれています。
静的サイトとして公開するときは、同じ `index.html` を配置してください。
この成果物では、一般公開URLへの反映は行っていません。

## 今回の変更

カウントダウン終了後は、大人用メニューを使わずに、画面下に2つのボタンを直接表示します。
「つぎへ いこう」の終了画面と、その後の「いっしょに、はじめよう。」の画面の両方が対象です。

- タイマーを最初から：終了したタイマーと同じ時間・同じ次の行動で、その場で再スタートします。
- 準備画面に戻る：追加確認なしで戻ります。準備画面の設定や表示する時間候補は維持します。

計測中・一時停止中は、これまでどおり約2秒長押しで大人用メニューを開きます。
メニューを開いている間にカウントダウンが終わった場合は、メニューを閉じて終了画面を表示します。
終了により非表示になったメニューボタンへキーボードフォーカスが残らないようにしています。

## 維持している内容

アニメーション・画像・咀嚼音・時間計算はv7から変更していません。
「あと、どれくらい？」のシンプルな時間ボタン、音・表示内の候補チェックボックス、任意の時間入力もそのままです。
「いま していること」の入力・表示は削除したままです。

## 動作確認

ChromiumにHTMLを直接読み込ませ、画面操作103項目が通過しました。
実際の4秒カウントダウン、20秒おためしの終了、終了後2画面での直接再スタート・戻る、キーボード操作、
計測中メニュー・一時停止、メニューを開いたままの終了、設定維持、320/390/768/1280px幅と横向き画面を確認しています。
また、時間計算・埋め込み素材・アニメーション描画・時間候補設定等の7部分がv7と同一であることを照合しました。

テスト方法：この実行環境はURL遷移が制限されるため、Playwrightのset_contentでHTMLを直接読み込んでいます。
カウントダウンは実時間で動かしています。保存復元を扱うテストはメモリー上の代替ストレージを使い、
ストレージが使えない場合の確認は代替なしで別途実施しています。実行時間制限のため、テストを分割して実行しました。
公開URL、iPhone/Android実機、ChatGPT内のプレビュー表示可否は未確認です。
検証結果は `validation` に収録しています。

## 利用上の注意

ChatGPTのプレビューが開かない場合は、ZIPを展開して `index.html` をブラウザで開いてください。
画面ロック中・別アプリ使用中の終了通知を保証するものではありません。画面を開いたまま使います。
